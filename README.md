# Datenschutzerklärung – Vinted Cross Lister

Dieses Tool ist nur für den privaten Eigengebrauch.
Es verarbeitet ausschließlich die eigenen Artikeldaten des Nutzers
(Titel, Beschreibung, Preis, Fotos) und legt sie als eBay-Angebote an.
Die Daten bleiben lokal auf dem Computer des Nutzers.
Es werden keine Daten an Dritte weitergegeben, verkauft oder
dauerhaft auf fremden Servern gespeichert.
Es werden keine Daten anderer eBay-Nutzer gespeichert.
